# Model card: prediction service unavailable

No production or research model artifact is shipped by the API. There is no genuine dengue surveillance series configured in the repository for a reproducible target, geographic join, temporal validation, and baseline comparison. Consequently `/api/v1/predictions` returns unavailable and does not expose a made-up risk score.

The legacy Streamlit CSV workflow can fit an exploratory Random Forest to user-provided weekly data and a deterministic synthetic demonstration dataset. Its output is not a validated outbreak warning. Before a backend model is enabled, document source/case definition, reporting cadence, forecast horizon, feature availability dates, chronological splits, seasonal baseline, metrics, model version, and uncertainty. Feature association is not causation. Outputs must be described as early-warning estimates, not confirmed outbreaks or medical advice.
